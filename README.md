# mind-atlas ── こころの地図

燻太さんと大河が、読んだ本から拾った **用語・人物・実験・理論** をつないでいく地図。
1つの用語が1つのファイルになっていて、`links` でつなぐと地図の上に線が引かれる。

公開URL： https://winforest1129-sys.github.io/mind-atlas/

---

## 運用のながれ

1. **本を読む** → 表紙と奥付を撮って共有 → `心理学/蔵書リスト.md` と `読書メモ/` に登録
2. **気になった用語を大河に伝える**
3. **大河が調べる** → `nodes/用語.md` を作り、`## 調べたこと` を書く
4. **地図に登録** → `python tools/build_map.py` → `data.json` が更新される
5. **燻太さんが `## 燻太さんの考え` を書く**
6. **次の本へ** → 1に戻る。用語が既にあれば `links` を足すだけで、本と本がつながる

この6番目が肝。**別の本で同じ用語に出会ったとき、地図の上で線がつながる**。
本単位のメモだけでは起きないことが、ここで起きる。

## ノードの書きかた

`nodes/` に1用語1ファイル。ファイル名がそのまま用語名になる（`label:` で上書きできる）。

```markdown
---
type: 用語            # 用語 / 人物 / 実験 / 症例 / 書物 / 理論
label: 中核意識        # 省略可。省略するとファイル名を使う
出典: 01_ダマシオ      # 蔵書リストの番号。カンマ区切りで複数可
確度: 推測            # 確認済（出典必須） / 推測 / 未調査
所持: 無              # 書物のときだけ。有 / 無 / 不明（既定）
入手:                 # 所持が「無」のときに書く。買える場所
  - {店: Amazon.co.jp, url: https://www.amazon.co.jp/dp/400029699X, note: ISBN-10 から}
links:
  - {to: 原自己, rel: 土台}
  - {to: 構成主義的情動理論, rel: 対立}
refs:
  - {title: 論文や記事の題, url: https://..., note: 何を確かめたか}
---
## 調べたこと
（大河が書く。推測と確認済みを混ぜない）

## 燻太さんの考え
（燻太さんが書く）
```

### refs（引用元）について

- **実際に当たった外部の情報源だけを書く。** 右パネルのいちばん下にリンクとして出る。
- **空でいい。** 空なら「外部の情報源には当たっていない。大河の記憶による」と正直に表示される。
  埋めることより、**記憶で書いたものを記憶だと分かるようにしておくこと**のほうが大事。
- `確度: 確認済` なのに refs が空だと、ビルドが警告を出す（書物と人物は除く）。
  出典を書くか、`推測` に落とすかのどちらか。
- ビルドの最後に「引用元つき N / M」が出る。**記憶で書かれた分がいくつ残っているかが毎回見える。**

### 説明欄（右パネル）の幅

**地図と説明欄のあいだのつまみを、左右にドラッグすると幅が変わる。**

- **ダブルクリックで既定（330px）にもどる。**
- 幅は**そのブラウザに覚えさせている**（`localStorage` の `mindatlas.sideW`）ので、次に開いても同じ幅。
- 下限260px、上限は画面幅の72%。窓を小さくすると自動で収まる。
- ⚠ **スマホでは効かない**（下からせり上がるシートになるので、幅の概念が無い）。

### 所持 と 入手（まだ買っていない本）

**読みたくなったときに、その場で買えるようにしておくための欄。**

- `所持: 無` を書くと、右パネルの**いちばん上**に「**まだ手元に無い**」の枠が出て、`入手:` のリンクが並ぶ。
  読んでいる途中で「これが要る」と気づいた本を、**探し直さずに買える**。
- `入手:` の書式は `- {店: 店の名前, url: https://..., note: 補足}`。
  ⚠ **refs（引用元）とは別物**。refs は「大河が実際に当たった情報源」、入手は「買える場所」。
  混ぜると、出典の欄に買い物リンクが紛れて、この地図のいちばん大事な線引きが濁る。
- **`所持: 無` なのに `入手:` が空だと、ビルドが警告を出す。** 逆に、入手があるのに所持が「無」でなくても警告。
- Amazon.co.jp のURLは **`https://www.amazon.co.jp/dp/<ISBN-10>`** で作れる。
  ⚠ ISBN-13 しか分からないときは**チェックディジットを計算し直す**こと
  （例 978-4-00-029699-1 → `400029699X`。末尾が `X` になることがある）。作ったら**実際に開いて確認する**。

- **`rel` に「対立」か「批判」が入ると、線が赤くなる。** どこで論争が起きているかが地図で見える。
- **`脳部位:` を書くと、右パネルに脳の模式図が出て、その領域が光る。**
  使えるIDは `tools/build_map.py` の `BRAIN_AREAS`（前頭前野 pfc／腹内側前頭前野 vmpfc／
  眼窩前頭皮質 ofc／背外側前頭前野 dlpfc／一次運動野 motor／体性感覚野 somatosensory／
  頭頂葉 parietal／後頭葉 occipital／側頭葉 temporal／島皮質 insula／前部帯状回 acc／
  後部帯状回 pcc／脳梁 corpus_callosum／扁桃体 amygdala／海馬 hippocampus／視床 thalamus／
  視床下部 hypothalamus／脳幹 brainstem／小脳 cerebellum）。カンマ区切りで複数可。
  知らないIDを書くとビルドが警告を出す。
- **`to` の用語がまだ無くてもいい。** 灰色の破線で「これから調べる」として地図に出る。
  消さずに残すと、**次に何を調べるかが地図の上に見えている**状態になる。
- 見出し（`## 〇〇`）は自由に足せる。そのまま右のパネルに出る。

## 画面の見かた

**左＝一覧パネル**（ヘッダーの「一覧」で開け閉め）
- **本でしぼる** … 本ごとのチェックを外すと、**その本〈だけ〉から派生したノードと線**が消える。
  複数の本にまたがる用語（例：ソマティック・マーカー仮説）は、どれか1冊でも表示中なら残る。
  **本と本をつなぐ橋を切らないため。** 出典を持たない概念と「これから調べる」は常に残る。
- **型ごとの一覧** … 書物／人物／理論／症例／実験／用語ごとの並び。クリックでその用語へ飛ぶ。
  **「記憶」の印**が付いているものは、外部の情報源に当たっていないノード。

**まんなか＝地図**。**右＝クリックした用語の中身**（本文 → 脳の図 → つながり → 引用元）。

## 更新の手順

```bash
# 1. nodes/ を書く・直す
# 2. ビルド（cwdはどこでもよい）
python tools/build_map.py
# 3. コミットして push
git add -A
git commit -m "add core consciousness node"
git push
```

⚠ **コミットメッセージは英語で、引用符（`"` `'`）を使わない。**
PowerShell 5.1 が引数を割ってしまい `pathspec did not match` で落ちる（植物図鑑で3回やらかした）。

⚠ **`data.json` は生成物だが、git に入れる。** GitHub Pages が読むファイルだから。
ビルドを忘れて push すると、地図が古いままになる。

## 中身

| もの | 何 |
|------|-----|
| `index.html` | 地図の本体。Cytoscape.js 3.34.2 を CDN から読む |
| `data.json` | `nodes/` から作られる。HTMLが読む |
| `nodes/*.md` | ⭐書く場所。1用語1ファイル |
| `brain.svg` | 脳の正中矢状断の解剖図。⭐**他人の著作物**（下のライセンスを見ること） |
| `tools/build_map.py` | `nodes/` → `data.json`。PyYAML不要（frontmatterは自前パース） |
| `.nojekyll` | Jekyllを止める。植物図鑑でビルドが10分タイムアウトして落ちた対策 |

植物図鑑（`plant-guide`）とは違って、**道具もリポジトリの中に入れてある**。
図鑑では `tools/` がリポジトリの外にあって、スクリプトの修正が履歴に残らないのが引っかかっていたため。

## ライセンスと出どころ

### `brain.svg`（脳の解剖図）

**この1ファイルだけは、他人の著作物である。**

- 原図：**Patrick J. Lynch, medical illustrator**
- 出どころ： https://commons.wikimedia.org/wiki/File:Brain_human_sagittal_section.svg
- ライセンス：**Creative Commons Attribution 2.5 Generic（CC BY 2.5）**
  https://creativecommons.org/licenses/by/2.5/
- 改変：mind-atlas で対話的な図の下敷きとして使っている。
  機能領域（vmPFC・dlPFC・vlPFC・ACC など）を上に重ねたのは本プロジェクトで、**原図には無い**。

CC BY 2.5 は **帰属表示と、改変した旨の明示**を求める。
サイト上では、図が出るたびにその下にクレジットを表示している。この表示を消してはいけない。

### 機能領域の位置について

⚠ **境界はおおよそである。**
解剖図に描いてあるのは構造（脳梁・視床・脳幹・小脳・脳回）であって、機能領域ではない。
機能領域の境界は研究によって定義が違う。
座標は下敷きの図に重ねて4回引き直し、目視で合わせたもので、それ以上の精度は無い。

破線で描かれる領域（扁桃体・海馬・島皮質・背外側前頭前野・腹外側前頭前野・側頭葉）は、
**この断面には現れない**（外側や深部にある）ため、位置だけを示している。

### それ以外

`nodes/` の文章、`index.html`、`tools/` は本プロジェクトのもの。
各ノードの内容の出どころは、ノードごとの `refs`（右パネルの「引用元」）に書いてある。
