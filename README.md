# mind-atlas ── こころの地図

燻太さんと大河が、読んだ本から拾った **用語・人物・実験・理論** をつないでいく地図。
1つの用語が1つのファイルになっていて、`links` でつなぐと地図の上に線が引かれる。

公開URL： https://winforest1129-sys.github.io/mind-atlas/

---

## 運用のながれ

1. **本を読む** → 表紙と奥付を撮って共有 → `心理学/蔵書リスト.md` と `読書メモ/` に登録
2. **気になった用語を大河に伝える**
3. **大河が調べる** → `nodes/用語.md` を作り、`## 調べたこと` を書く
4. **地図に登録** → `python tools/build_map.py` → `data.json` が更新される
5. **燻太さんが `## 燻太さんの考え` を書く**
6. **次の本へ** → 1に戻る。用語が既にあれば `links` を足すだけで、本と本がつながる

この6番目が肝。**別の本で同じ用語に出会ったとき、地図の上で線がつながる**。
本単位のメモだけでは起きないことが、ここで起きる。

## ノードの書きかた

`nodes/` に1用語1ファイル。ファイル名がそのまま用語名になる（`label:` で上書きできる）。

```markdown
---
type: 用語            # 用語 / 人物 / 実験 / 症例 / 書物 / 理論
label: 中核意識        # 省略可。省略するとファイル名を使う
出典: 01_ダマシオ      # 蔵書リストの番号。カンマ区切りで複数可
確度: 推測            # 確認済（出典必須） / 推測 / 未調査
links:
  - {to: 原自己, rel: 土台}
  - {to: 構成主義的情動理論, rel: 対立}
refs:
  - {title: 論文や記事の題, url: https://..., note: 何を確かめたか}
---
## 調べたこと
（大河が書く。推測と確認済みを混ぜない）

## 燻太さんの考え
（燻太さんが書く）
```

### refs（引用元）について

- **実際に当たった外部の情報源だけを書く。** 右パネルのいちばん下にリンクとして出る。
- **空でいい。** 空なら「外部の情報源には当たっていない。大河の記憶による」と正直に表示される。
  埋めることより、**記憶で書いたものを記憶だと分かるようにしておくこと**のほうが大事。
- `確度: 確認済` なのに refs が空だと、ビルドが警告を出す（書物と人物は除く）。
  出典を書くか、`推測` に落とすかのどちらか。
- ビルドの最後に「引用元つき N / M」が出る。**記憶で書かれた分がいくつ残っているかが毎回見える。**

- **`rel` に「対立」か「批判」が入ると、線が赤くなる。** どこで論争が起きているかが地図で見える。
- **`to` の用語がまだ無くてもいい。** 灰色の破線で「これから調べる」として地図に出る。
  消さずに残すと、**次に何を調べるかが地図の上に見えている**状態になる。
- 見出し（`## 〇〇`）は自由に足せる。そのまま右のパネルに出る。

## 更新の手順

```bash
# 1. nodes/ を書く・直す
# 2. ビルド（cwdはどこでもよい）
python tools/build_map.py
# 3. コミットして push
git add -A
git commit -m "add core consciousness node"
git push
```

⚠ **コミットメッセージは英語で、引用符（`"` `'`）を使わない。**
PowerShell 5.1 が引数を割ってしまい `pathspec did not match` で落ちる（植物図鑑で3回やらかした）。

⚠ **`data.json` は生成物だが、git に入れる。** GitHub Pages が読むファイルだから。
ビルドを忘れて push すると、地図が古いままになる。

## 中身

| もの | 何 |
|------|-----|
| `index.html` | 地図の本体。Cytoscape.js 3.34.2 を CDN から読む |
| `data.json` | `nodes/` から作られる。HTMLが読む |
| `nodes/*.md` | ⭐書く場所。1用語1ファイル |
| `tools/build_map.py` | `nodes/` → `data.json`。PyYAML不要（frontmatterは自前パース） |
| `.nojekyll` | Jekyllを止める。植物図鑑でビルドが10分タイムアウトして落ちた対策 |

植物図鑑（`plant-guide`）とは違って、**道具もリポジトリの中に入れてある**。
図鑑では `tools/` がリポジトリの外にあって、スクリプトの修正が履歴に残らないのが引っかかっていたため。
