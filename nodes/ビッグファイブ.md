## 調べたこと
Big Five / 五因子モデル（FFM）。パーソナリティを**5つの連続量**で捉える、学術的な標準。

**外向性 / 協調性 / 誠実性 / 神経症的傾向 / 開放性**（頭文字を並べて **OCEAN**）

⭐ この地図では**ハブ**の位置にいる。`03_ジーグラーヒル` の狙いが「病理的なパーソナリティ特徴を
ビッグファイブ次元と結びつける」ことなので、ダークな特性の話はすべてここに接続する。

### 5つの定義（John ら 2008, Table 4.2）
⭐ **一つずつのノードに分けてある** → [[外向性]] [[協調性]] [[誠実性]] [[神経症的傾向]] [[開放性]]
（各ノードに、定義・BFI-2の3ファセット・測りやすさ・何を予測するか・弱点を入れた）

| 因子 | 何を対比しているか |
|---|---|
| 外向性 E | 社会的・物質的世界への**エネルギッシュな接近**（社交性・活動性・自己主張・肯定的情動） |
| 協調性 A | **向社会的・共同的な方向づけ** ⇔ **敵対（antagonism）**（利他性・優しさ・信頼・慎み） |
| 誠実性 C | 課題と目標に向かうための**社会規範的な衝動制御**（考えてから動く・満足を先延ばす・計画する） |
| 神経症的傾向 N | **情緒安定** ⇔ **否定的情動性**（不安・緊張・悲しみ） |
| 開放性 O | 精神生活と経験の**幅・深さ・独創性・複雑さ** |

⭐ 右列の太字は偶然ではない。`03_ジーグラーヒル` のPart名（**敵対／脱抑制／否定的情動性**）は、
**[[DSM-5代替モデル]] の病理的特性領域の名前**であり、その領域は**五因子の病理的な極として設計されている**。
編者がそう決めたと明言している（2026-08-31に原著イントロで確認）。
ただし本書のPart 3 **[[柔軟性の欠如]]** だけはDSM-5に無い ── そこが面白いところ。

## ⭐名前の由来 ── 「大きい」ではなく「広い」
「Big Five」と名づけたのは **Goldberg (1981)**。ただしこれは
**5つが偉いという意味ではなく、一つひとつが極端に広い（broad）ことを強調するため**だった、と総説は明言している。

だから「人格は5つに還元できる」という主張ではない。5因子は**とても粗い抽象度の層**であって、
その下に無数のより具体的な特性がぶら下がっている。総説の比喩がわかりやすい ──
**グッピーと言うほうが、魚と言うより情報が多い。魚と言うほうが、脊椎動物と言うより情報が多い。**
ビッグファイブは生物でいう「植物」「動物」くらいの位置にいる。**帯域は広いが、忠実度は低い。**

## ⚠ どこまで確かなのか（ここが一番大事）
- **普遍的だと確定してはいない。** ゲルマン語圏ではよく再現するが、非西洋の言語では話が複雑になる。
  総説自身が引く結論は「**現時点で最良の作業仮説**（best working hypothesis）」まで。
- **一番あやしいのは第5因子（開放性）**。ドイツ語では純粋な「知性」、オランダ語・イタリア語では
  「非慣習性・反抗性」として出てくる。**言語によって別のものを指してしまう。**
- **因子を減らしたほうが（2つや3つ）再現性が高いことすらある。**
- 逆に**6因子**（Ashton ら 2004）を支持する再分析もある → [[HEXACO]]
- ⭐ただし総説は同時に、**言語相対主義の否定**という強い結果も指摘している。
  「文化ごとに固有の人格次元がある」という予想は**データに支持されなかった**。広い次元のレベルでは、文化は予想よりずっと似ている。
- **理論ではなく分類学**。Big Five は**記述するもの**であって、**説明するものではない**（Goldberg 1993）。
  なぜそうなるかを言う理論は、McCrae & Costa の五因子理論など別立て。

## 測る道具（手元にPDFがある6本）
**唯一の標準（gold standard）はない**、と総説ははっきり書いている。用途で選ぶもの。

| 尺度 | 項目数 | 位置づけ |
|---|---|---|
| NEO-PI-R / NEO-FFI | 240 / 60 | 質問紙系で最もよく検証されている |
| TDA（Goldberg 1992） | 100（短縮40） | 単語1語で答える形式の定番 |
| **BFI-2**（Soto & John 2017） | 60 | いま新しく測るならこれ。**15ファセット**の階層構造つき |
| BFI-10（Rammstedt & John 2007） | 10 | 1分版 |
| Mini-IPIP（Donnellan 2006） | 20 | IPIP由来。α ≧ .60 |
| TIPI（Gosling 2003） | 10 | ⚠**著者自身が「標準尺度に劣る」と明記**。使うなら時間がない時だけ |
| IPIP（Goldberg 2006） | 可変 | ⭐**パブリックドメイン**。著作権に縛られない |

**信頼性**（Berkeley 829名, BFI/TDA/NEO-FFI）＝ α平均 .84 / .83 / .81。
**尺度間の収束的妥当性**＝平均 r = .75（信頼性で補正すると .93）。弁別的相関は平均 .19。
⚠ただし **E・A・C は .95 前後で一致するのに、N（.86）と O（.90）は落ちる**。
とくにNEO-FFIの開放性は、他の2尺度とかみ合いが悪い。**同じ「開放性」という名前でも中身が同じとは限らない。**

## ⭐MBTIに神経症的傾向の軸がない理由がわかった
燻太さんはMBTIとの対応を学習ずみだった（E/I=外向性、S/N=開放性、T/F=協調性、J/P=誠実性。
**神経症的傾向に対応する軸がない**）。総説の Table 4.1 はこの対応をそのまま裏づけている。
本文でも、MBTIの4尺度は **extraversion / feeling / judging / intuition を測る** と書かれていて、5つ目がない。

⭐**そして、なぜ無いのかまで書いてある。**

> 情緒安定は2番目にほぼ普遍的に認められる次元だが、Table 4.1 の研究者全員が
> それに独立した尺度を置いているわけではない。とくにそうなのが、**基本的に健常でよく機能している大人の
> アセスメントを主目的とする質問紙** ── Gough の CPI、**MBTI**、Jackson の PRF である。

つまり**MBTIに神経症的傾向が無いのは、うっかり漏れたのではなく、健常者の「タイプ分け」という
出自からくる設計上の選択**だということになる。裏返すと、**MBTIは苦しさの次元を最初から見ない道具**になっている。
（気質ベースのモデルは、逆に全部が神経症的傾向を含んでいる）
