## これは何か
「その段階に、成人の何割がいるのか」。理論の魅力とは別に、==いちばん先に見るべき数字==。

## Kegan の枠（主体・客体インタビュー。Kegan 1994 が集めた研究、19〜55歳。Berger 2003 の要約）
| 段階 | 割合 |
|---|---|
| 第2 か 2→3 移行 | 13〜36%（集団による） |
| 第3 か 3→4 移行 | **43〜46%** |
| 第4 | 18〜34% |
| 4→5 移行 | 3〜6% |
| 第5 | ==**0**==（報告された研究の中に一人もいない） |

Berger の留保＝年齢層が若いので、年上の集団ではもう少しいるだろう。Kegan＝第5は中年より前には見られない。

## Cook-Greuter の枠（文章完成テスト。n=4,510。一般成人＋多様な職業）
| 行動論理 | 割合 |
|---|---|
| Opportunist | 4.3% |
| Diplomat | 11.3% |
| Expert | 36.5% |
| Achiever | 29.7% |
| Individualist | 11.3% |
| Strategist | 4.9% |
| Magician（Alchemist） | **2.0%** |

## 読むときの歯止め
- ==二つの表は物差しが違う==（面接 vs 文章完成）。段階の対応もおおよそ（[[行動論理]]）
- どちらも**便宜標本**。Cook-Greuter は「囚人から聖職者まで」と書くが、無作為抽出ではない
- 「第5段階が 0」は「存在しない」ではなく「この標本には出なかった」。
  ただし==理論家の側も、実在の根拠として集団の数字を持っていない==（事例研究と推定）
- `07_ラスキー` は S-5 をコーチの理想像として描くが、その理想像に該当する人がどれだけいるかは本に無い
