## 調べたこと
**Conscientiousness（誠実性、C因子）**。[[HEXACO]] の第5因子。
⭐ ビッグファイブの [[誠実性]] と**ほぼ共通**。

### 4つのファセット（HEXACO-PI-R）
| ファセット | |
|---|---|
| **秩序性** Organization | 身のまわりや段取りを整える |
| **勤勉さ** Diligence | 骨の折れる課題に取り組む |
| **完全主義** Perfectionism | 細部の誤りを見逃さない |
| **慎重さ** Prudence | 衝動で動かず、考えてから決める |

高い人は**規律正しく、熟慮する**。低い人は**衝動的で、秩序に無頓着**。

## ⚠ ビッグファイブとの違い
| | |
|---|---|
| ビッグファイブ（BFI-2） | 秩序性 ／ 産出性 ／ ⭐**責任性**（＝人から当てにされるか） |
| HEXACO | 秩序性 ／ 勤勉さ ／ ⭐**完全主義** ／ ⭐**慎重さ** |

⭐ **HEXACOは「完全主義」を独立のファセットとして立てている。**
⚠ これは地図の [[柔軟性の欠如]] に直結するかもしれない ──
[[パーソナリティのダークサイド]] の Part 3 の第10章がまさに**対人的完全主義**で、
その部が置かれた理由は「**PID-5が誠実性の高極を拾えないから**」だった。
⭐ **HEXACOは、誠実性の高極にあたるものを最初からファセットに入れている**ことになる。
⚠ ただしこの対応づけは大河の見立てで、文献で確かめていない。**要確認。**

⭐ 一方 HEXACO には、ビッグファイブ側の**「責任性」＝人から当てにされる度合い**にあたる
ファセットが見当たらない。Soto & John が**向社会的な成分**と呼んだ部分で、
HEXACOではおそらく [[正直さ-謙虚さ]] や [[HEXACOの協調性]] のほうに回っている。
⚠ これも大河の推測。**未調査。**
