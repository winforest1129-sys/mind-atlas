## 調べたこと
**eXtraversion（外向性、X因子）**。[[HEXACO]] の第3因子。
⭐ ビッグファイブの [[外向性]] と**ほぼ共通**。回転していない3つのうちのひとつ。

### 4つのファセット（HEXACO-PI-R）
| ファセット | |
|---|---|
| **社会的自尊心** Social Self-Esteem | 自分を人づきあいの中で価値ある存在だと感じる |
| **社会的大胆さ** Social Boldness | 人前や見知らぬ場面で臆さない |
| **社交性** Sociability | 人と一緒にいることを楽しむ |
| **快活さ** Liveliness | 元気で機嫌がよい |

高い人は**社会的な場面で自信があり、活力に満ちている**。低い人は**引っ込みがちで、意気があがらない**。

## ⚠ ビッグファイブとの違い（あるにはある）
| | |
|---|---|
| ビッグファイブ（BFI-2） | 社交性 ／ **自己主張性** ／ 活力水準 |
| HEXACO | 社交性 ／ 社会的大胆さ ／ 快活さ ／ ⭐**社会的自尊心** |

⭐ **HEXACOは「社会的自尊心」を外向性の中に置いている。**
自分を人づきあいの中でどう評価しているか、という**自己評価の成分**が入っている点が目立つ。
⚠ ビッグファイブ側の「自己主張性」に相当するのは、HEXACOでは「社会的大胆さ」のほうに近い。

⭐ **同じ「外向性」でも、道具によってファセットの割り方が違う**のは
ビッグファイブの内部でも起きていること（NEOとBFIで温かさの扱いが割れる → [[外向性]]）。
**HEXACOとの差も、その延長線上にある程度の違い**だと見ておくのがよさそうだ。
⚠ ただし両者を直接比べた研究には当たっていない。**未調査。**
