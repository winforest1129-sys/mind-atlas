## 背骨
**人間の感覚を「基準」にして他の動物を測らない。** それぞれの環世界に優劣はなく、
それぞれの生き方に最適化されている ── これが全体を貫く主張。

## ⭐構成が主張そのものになっている
全13章が、ひとつずつ感覚モダリティに対応している。

**匂いと味 → 光 → 色 → 痛み → 熱 → 接触と流れ → 表面振動 → 音 → エコー → 電場 → 磁場
→ 感覚の統合 → 脅かされる感覚風景**

⭐ **人間が持つ感覚から始まり、人間に無い感覚へ進み、最後に「統合」と「破壊」で閉じる。**
読者は自分の環世界の内側から出発して、少しずつ外へ連れ出される作りになっている。

1. **13章のうち5章が、人間に対応する器官の無い感覚**（表面振動・エコー・電場・磁場、そして紫外の色）。
   本の重心は明らかにそこ。
2. **第12章「同時にすべての窓を見る ── 感覚の統合」が構成上の要。**
   1〜11章がモダリティごとにばらばらなのは、12章でそれを畳むためだと思う。
   環世界は感覚の寄せ集めではなく、**統合された一個の世界**だという話に着地するはずだ。
3. ⭐⭐ **第13章が「脅かされる感覚風景」で終わる。**
   ⚠ **これは博物学の本であると同時に、保全（conservation）の本でもある。**
   光害・騒音が他の動物の環世界を壊しているという主張で閉じる。
   環世界という概念が、**倫理的な射程**まで連れていかれる。
   ※構成は目次で確認ずみ。**3の解釈は大河の推測**で、本文ではまだ確かめていない。
