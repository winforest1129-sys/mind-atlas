## 調べたこと
**Honesty-Humility（正直さ-謙虚さ、H因子）**。[[HEXACO]] の6つ目の因子であり、**本体**。
⭐ **ビッグファイブに対応するものが無い、唯一の因子。**

### 4つのファセット（HEXACO-PI-R）
| ファセット | |
|---|---|
| **誠実さ** Sincerity | 対人関係で飾らない |
| **公正さ** Fairness | 不正やごまかしを避ける |
| **欲のなさ** Greed Avoidance | 富や贅沢、高い地位に興味が薄い |
| **謙虚さ** Modesty | 自分を特別扱いしない |

高い人は**自分の利益のために他人を操作することを避ける**。
低い人は**欲しいものを得るために人におもねり**、物質的な利得を追う。

## ⭐⭐ この因子が地図に効く理由
[[ダーク・トライアド]] の核心は「**概念的には別なのに、測ると重なる**」ことだった。
その重なりを何が作っているのか ── **H因子がひとつの答えを出している。**

| | 五因子の [[協調性]] | **正直さ-謙虚さ** |
|---|---|---|
| サイコパシー | −.39 | **−.72** |
| マキャベリアニズム | −.44 | **−.57** |
| [[自己愛]] | **−.04** | **−.53** |

⚠ **自己愛だけが協調性とほぼ無相関**で、五因子の枠組みでは行き場を失う。
ところがH因子から見ると3つはきれいに並ぶ。

⭐ さらに決定的なのは、**ダーク・トライアド3特性のあいだの相関**を
**HEXACOの変数は満足に説明できたが、五因子モデルの変数では説明できなかった**という結果のほう
（Lee & Ashton 2005）。
つまり [[ダーク・トライアド]] が「冷淡な操作性」と呼んだものは、
**正直さ-謙虚さの低極**として測れるかもしれない。

## なぜこの因子が必要なのか（理論の側）
Ashton & Lee (2007) は、H因子と [[HEXACOの協調性]] がともに
**互恵的利他行動（reciprocal altruism）** ── 他人を搾取するのではなく助け協力する傾向 ── を
測っているとする。H因子は**向社会的・利他的な振る舞いへの傾き**にあたる。
⚠ この理論的説明は二次的な解説を通して確認したもので、原論文そのものには当たっていない。

## ⚠ ただし決着はついていない
ビッグファイブ側（John ら 2008）は慎重で、
**5因子より多い因子は独立した複数の研究で再現しにくい**と指摘している。
⭐ **ダークな特性を扱う一点に絞れば**HEXACOの説明力が高い、というのが今わかっていること。
